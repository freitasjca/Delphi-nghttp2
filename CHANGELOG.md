# Changelog

Full notes for every release — what changed, why, and what to watch when
upgrading — live on the
[GitHub Releases page](https://github.com/freitasjca/Delphi-nghttp2/releases).
That is the authoritative record.

This file is an index: every tagged version, its date, and the headline where the
release carries one. Versions listed without a headline are point releases whose
notes are on their release page.

The project has been on `1.x` since its first public tag.
